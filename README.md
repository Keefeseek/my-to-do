# 📋 待办事项 - Todo App

一个功能丰富、界面简洁的待办事项网页应用。无需安装，打开浏览器即可使用，数据保存在本地，保护你的隐私。

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| ➕ 添加任务 | 输入任务名称，按回车或点击按钮即可添加 |
| ✅ 完成任务 | 点击任务左侧的圆圈标记完成/取消完成 |
| 🗑️ 删除任务 | 悬停任务后点击 ✕ 按钮，确认后删除 |
| 🔴🟡🟢 紧急程度 | 每个任务可设为紧急、一般、不急，自动按优先级排序 |
| 📝 备注 | 点击备注图标展开，支持多行文本 |
| 📅 日期规划 | 为任务指定日期，逾期未完成自动红色警告 |
| 🕐 时间设置 | 可选填开始/结束时间，支持跨天（如 22:00 - 02:00） |
| 📆 日历视图 | 月历显示任务分布，点击日期筛选当天任务 |
| 🕐 日程表 | 时间线视图展示当天日程，按时间段显示色块 |
| 🌙 深色模式 | 一键切换亮色/暗色主题 |
| 📤 导出数据 | 将所有任务导出为 JSON 文件备份 |
| 📥 导入数据 | 上传 JSON 文件恢复任务 |

## 📖 使用指南

### 一、添加任务

1. 在左侧「✏️ 输入新任务」框中输入任务名称
2. 选择紧急程度：🔴 紧急 / 🟡 一般（默认）/ 🟢 不急
3. 选择日期（默认今天）
4. 可选：填写开始时间和结束时间（留空则为全天事项）
5. 点击「➕ 添加任务」或直接按 **Enter** 键

### 二、管理任务

| 操作 | 方法 |
|------|------|
| 标记完成 | 点击任务左侧的 **圆圈** ⭕ |
| 修改紧急程度 | 点击任务上的紧急标签（如「🔴 紧急」），弹出选择器 |
| 添加备注 | 点击任务右侧的 **📄 图标**，展开备注区域输入 |
| 删除任务 | 鼠标悬停任务 → 点击右侧 **✕** → 确认删除 |

### 三、日历功能

1. 点击左侧「📅 日历」展开月历
2. 有任务的日期会显示彩色圆点
3. **点击某一天**：筛选只显示该天的任务
4. **再次点击同一天** 或点击「显示全部」：恢复显示所有任务
5. 使用 ◀ ▶ 箭头切换月份

### 四、日程表视图

1. 点击右侧顶部的「🕐 日程表」标签切换
2. 时间线显示 6:00 ~ 24:00 的任务色块
3. 没有设置时间的任务显示在顶部「全天事项」区域
4. 红色横线标记当前时刻
5. 鼠标悬停色块可查看任务详情
6. 跨天任务（如 22:00 - 02:00）会在两天的日程表中分别显示

### 五、统计面板

页面左上角三个统计卡片实时显示：
- 🔵 **今日任务**：今天的任务总数
- 🟢 **已完成**：所有已完成任务数
- 🔴 **已逾期**：过期且未完成的任务数

### 六、深色模式

点击右上角的 **主题切换开关**（☀️ / 🌙）即可切换。选择会自动记住。

### 七、数据备份

- 点击左下角 **📤 导出**：下载 JSON 备份文件
- 点击左下角 **📥 导入**：选择之前导出的 JSON 文件恢复数据

> ⚠️ 导入会覆盖当前所有数据，请谨慎操作。

## ❓ 常见问题

**Q: 数据存在哪里？安全吗？**
> 所有数据保存在你自己的浏览器本地存储（localStorage）中，不会上传到任何服务器，完全私密。

**Q: 换设备/换浏览器数据还在吗？**
> 不在。数据绑定在当前浏览器中。可以使用「导出/导入」功能手动迁移。

**Q: 清除浏览器缓存会丢数据吗？**
> 会。建议定期使用「📤 导出」功能备份。

**Q: 手机上操作不方便？**
> 建议将网页添加到主屏幕，横屏体验更佳。应用已做响应式适配，手机端布局会自动调整。
